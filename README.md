# Patrimar RI: proposta conceitual da GSA

Redesenho conceitual do site de Relações com Investidores do Grupo Patrimar, feito pela Gustavo Santos Analytics com dados públicos.

**Proposta conceitual da GSA. Não é o site oficial de RI do Grupo Patrimar**, não substitui os documentos da companhia e não é recomendação de investimento. Site oficial: https://ri.patrimar.com.br/

Este repositório contém só o site estático publicado no GitHub Pages. A página está marcada como `noindex`.
